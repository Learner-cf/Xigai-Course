# 中美个人信息保护立法比较

> 核查基准日：2026 年 10 月 17 日
> 证据编号：见 `04_参考资料与证据索引.md`（E21、E35 为 CCPA 法条与金额的官方依据）
> 标注规则：【事实】=法律文本或官方文件直接规定的内容；【分析】=整理者对制度理念、政策取向的概括，属研究性判断；【待核实】=未取得可打开的权威一手来源。
> 本文件为第二轮核查后版本：已按 CPPA 官方通胀调整公告修正金额，并补充"同意并非唯一合法基础""加州同样有最小必要/比例性要求"等内容。

## 〇、比较范围、层级与边界（先说清楚，避免以偏概全）

- 【事实】中国一侧是**全国性法律**：《个人信息保护法》《数据安全法》《网络安全法》，加配套行政法规《网络数据安全管理条例》（E04、E05、E01/E02、E07）。
- 【事实】美国一侧没有同等层级的单一法：联邦层面主要依《联邦贸易委员会法》第 5 条等分行业/通用执法条款（15 U.S.C. §45，E31），综合性联邦隐私立法 H.R. 8818（APRA）2024 年仅"提出"、未成为法律（E32）；本文件以**加州州法 CCPA（经 CPRA 修正）**为主要样本（E21）。
- 【事实】CCPA 仅保护"consumer"，即**加州居民**（E21 §1798.140）。
- 【分析】边界一：**全国性法律与州法不属于对等层级**，比较的是"中国全国性制度"与"美国（加州）制度"。
- 【分析】边界二：**CCPA 不能代表美国全部隐私保护法律**；联邦分行业法与各州法并存。CCPA 自身即豁免依 HIPAA、FCRA、GLBA 等联邦法处理的信息（E21 §1798.145）。
- 【分析】边界三：不把中美差异简化为"国家安全 vs 个人自由"的二元对立，也不把任何一方描述为绝对先进或绝对落后。
- 【分析】本文件所有制度取向、优劣评价均为研究者分析，不得当作法律规定引用。

## 一、比较总表（金额均为 2026 年现行适用值）

| 比较维度 | 中国 | 美国（联邦总体／加州 CCPA） |
|---|---|---|
| 立法体系 | 【事实】全国性专门立法 + 配套行政法规（E04、E05、E01/E02、E07） | 【事实】联邦无统一综合性隐私法，主要靠 FTC 依 §45 执法与分行业立法；州法填补空缺，加州 CCPA 为代表（E31、E32、E21） |
| 适用范围 | 【事实】PIPL：境内处理自然人个人信息活动，及符合条件的域外情形（E04 第三条）；DSL：境内数据处理及安全监管（E05 第二条） | 【事实】CCPA 适用于在加州经营且满足门槛的"business"，保护加州居民（E21 §1798.140） |
| 主体门槛 | 【事实】PIPL/DSL 无营业额门槛；对"处理个人信息达到国家网信部门规定数量"者加重义务（E04 第五十二、五十六条） | 【事实】满足其一即适用：上一年度年总收入超过 **26,625,000 美元**（2025-01-01 起调整值，原 25,000,000）；或年购买/出售/共享 **100,000** 名以上消费者或家庭信息；或 **50%** 以上年收入来自出售/共享个人信息（E21 §1798.140(d)(1)、E35） |
| 处理合法性基础 | 【事实】同意并非唯一基础：PIPL 第十三条列七类情形（同意、合同必需、法定义务、突发公共卫生事件或紧急情况、新闻报道/舆论监督、处理已合法公开信息、法律行政法规规定的其他情形），其中第（二）至（七）项**不需取得同意**（E04 第十三条） | 【事实】CCPA 以"收集时告知 + 消费者权利（退出/限制）"为主要机制，不以"逐项同意"为处理前提（E21 §1798.100、§1798.120、§1798.121） |
| 数据收集与使用限制 | 【事实】合法、正当、必要、诚信；目的明确合理、影响最小、**最小范围**、不得过度收集（E04 第五、六条）；《条例》要求清单式告知（E07 第二十一条） | 【事实】CCPA **同样有**必要性与比例性要求：企业的收集、使用、保留与共享须"reasonably necessary and proportionate"（合理必要且相称）以实现收集目的或兼容目的，且不得用于不兼容目的（E21 §1798.100(c)）；配套法规 §7002 进一步以"消费者合理期待"为标准，并举例：手电筒 App 不应为提供手电服务而收集地理位置（E22 §7002） |
| 个人信息权利 | 【事实】知情权、决定权、限制或拒绝处理（第四十四条）；查阅复制、可携带（第四十五条）；更正补充（第四十六条）；删除（第四十七条）；解释说明（第四十八条）；自动化决策重大影响可拒绝（第二十四条）（E04） | 【事实】知情/查阅（§1798.110）、知悉出售共享对象（§1798.115）、删除（§1798.105）、更正（§1798.106）、退出出售/共享（§1798.120）、限制敏感个人信息使用（§1798.121）、不受歧视（§1798.125）（E21） |
| 敏感信息规则 | 【事实】敏感个人信息（生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等及不满十四周岁未成年人信息）须特定目的、充分必要并取得**单独同意**（E04 第二十八条、第二十九条） | 【事实】"sensitive personal information"（SPI）含社会安全号、账户登录名与密码、精确地理位置、种族/民族、公民或移民身份、宗教信仰、工会身份、邮件/短信内容、基因数据、神经数据等；企业若将 SPI 用于"服务必需"以外目的，须告知并提供**限制使用（right to limit）**机制（E21 §1798.121、§1798.140） |
| 企业合规义务 | 【事实】安全措施、个人信息保护负责人、合规审计、个人信息保护影响评估、泄露通知、大型平台特殊义务（E04 第五十一—五十八条） | 【事实】收集时告知与隐私政策、至少两种行权方式、45 天内响应（可延 45 天）、与第三方/服务商签订限制用途的合同、尊重退出偏好信号（如 Global Privacy Control）、数据泄露诉讼的前提是"未采取合理安全措施"（E21 §1798.100(d)、E29、E30、§1798.150） |
| 监管与执法 | 【事实】国家网信部门统筹，多部门分工（E04 第六十条）；可组织测评并公布结果（第六十一条）；民事赔偿（第六十九条）、公益诉讼（第七十条） | 【事实】CPPA 负责规则制定与**行政罚款**（§1798.155）；加州总检察长可在法院提起**民事罚款**之诉（§1798.199.90）；2023-01-01 起取消整改期（E21、E30、E35） |
| 处罚金额（现行） | 【事实】PIPL 情节严重：5,000 万元以下或上一年度营业额 5% 以下（E04 第六十六条）；DSL 最高可达 200 万—1,000 万元（E05 第四十五、四十六条） | 【事实】行政罚款/民事罚款：每次违规不超过 **2,663 美元**；故意违规或涉及已知未满 16 岁消费者信息的每次不超过 **7,988 美元**（2025-01-01 起调整值，原 2,500/7,500）（E21 §1798.155(a)、§1798.199.90(a)、E35） |

| 数据跨境流动 | 【事实】PIPL 第三章：安全评估、专业认证、标准合同等条件之一，并须告知与取得单独同意（E04 第三十八—四十条）；国家机关处理的个人信息境内存储、确需出境进行安全评估（第三十六条）；DSL：重要数据出境另有规定（第三十一条）（E04、E05） | 【事实】CCPA 未设同类出境审批机制（E21）。【待核实】美国联邦层面的跨境数据传输规则本轮未取得可打开的官方原文（E33） |
| 制度取向 | 【事实】PIPL 第一条"保护个人信息权益…促进个人信息合理利用"；DSL 第一条、第四条将数据安全与"国家主权、安全和发展利益""总体国家安全观"相连（E04、E05） | 【事实】CCPA 文本聚焦消费者权利与企业义务，未采用"国家安全"框架（E21） |

## 二、对两个常见简化说法的纠正

### 2.1 "中国＝事前同意＋最小必要"

- 【事实】不准确之处：PIPL 第十三条明确规定七类合法处理基础，**同意只是其中之一**；该条第二款进一步说明，属于第（二）至（七）项情形的，**不需取得个人同意**（E04 第十三条）。
- 【事实】同意规则本身也有边界：同意须自愿、明确、充分知情（第十四条），可撤回且须提供便捷方式（第十五条），不得因不同意/撤回而拒绝提供产品或服务（第十六条）（E04）。
- 【分析】因此更准确的表述是："中国以**多类合法性基础**为前提，其中同意是最常见的一类；并在收集阶段适用**目的限定与国家强制的最小必要要求**。"

### 2.2 "加州＝告知＋事后退出"

- 【事实】不准确之处：CCPA 并不是"随便收集、只要告知即可"。§1798.100(c) 要求企业的收集、使用、保留与共享**合理必要且相称**于既定或兼容目的，且不得用于不兼容目的（E21）；配套法规 §7002 以"消费者合理期待"为标准细化，并明确企业在收集前须评估目的正当性（E22 §7002）。
- 【事实】此外，当企业把敏感个人信息用于"提供服务所必需"以外的目的时，须告知并提供限制使用机制（§1798.121）；出售/共享须提供退出机制并可识别退出偏好信号（§1798.120、§1798.135）（E21）。
- 【分析】因此更准确的表述是："加州以**目的限定与必要/比例性**为实体约束，以**告知 + 退出/限制**为个人控制机制，并以**法定赔偿与行政/民事罚款**为执行手段。"

## 三、分项详述：法律事实 → 制度差异 → 取向 → 优劣 → 对青年的启示

### 3.1 立法体系与层级

- 【事实】中国为"法律 + 行政法规"体系；美国联邦缺综合性法，由分行业法与州法共同填补，且 CCPA 明确豁免受 HIPAA/FCRA/GLBA 等联邦法约束的信息（E21 §1798.145）。
- 【分析】差异：中国一次立法覆盖所有行业；美国呈"联邦分行业 + 各州综合"的拼图结构。局限：前者需靠配套规则细化落地，后者存在企业合规碎片化与"逐州补丁"问题。
- 【分析】对青年启示：在中国，日常 App、快递、校园系统通常都落入 PIPL/条例的适用范围；在美国语境下，"是否受某隐私法保护"取决于主体门槛、州籍与行业豁免。

### 3.2 主体门槛与保护对象

- 【事实】PIPL 无营业额门槛（E04）；CCPA 有三重门槛且仅保护加州居民（E21、E35）。
- 【分析】差异：中国制度对小微经营者同样设定一般义务；加州对小企业可豁免。局限：门槛式立法降低小企业合规成本，但也留下覆盖空白；无门槛立法覆盖面广，但执法资源与合规负担压力更大。
- 【分析】对青年启示：门槛是"企业是否受约束"的判断标准，不等于"公民是否受保护"；在中国，学生与校内小型服务提供者同样受法律约束。

### 3.3 合法性基础与数据最小化

- 【事实】见本文件 2.1、2.2 及总表对应行（E04 第十三条、第六条；E21 §1798.100(c)、§1798.121；E22 §7002）。
- 【分析】差异：中国以"合法性基础清单 + 最小必要"为事前约束，主要体现在收集环节；加州以"目的限定 + 合理期待 + 事后退出/限制"组合为主。
- 【分析】优劣：前者事前门槛清晰、便于统一执法，但需防止把"同意"形式化；后者给了消费者直接控制权与诉讼救济，但对"未行使权利"的消费者保护较弱。
- 【分析】对青年启示：在中国，遇到强制索权可据 PIPL 与《认定方法》主张；在加州语境下，即便企业已告知，若收集目的不符合合理期待，仍可能违反必要/比例性要求。

### 3.4 敏感信息

- 【事实】中国：单独同意 + 特定目的 + 充分必要性（E04 第二十八、二十九条）。加州：SPI 定义 + 限制使用机制（E21 §1798.121、§1798.140）。
- 【分析】差异：中国采"事前单独同意"路径，加州采"事后限制使用"路径。优劣：前者更能预防不当处理，后者行政与个人成本更低但依赖消费者主动行权。
- 【分析】对青年启示：身份证号、人脸、行踪轨迹、金融账户等在两地均属高敏感类别，应尤其避免在来源不明的页面或 AI 工具中提交。

### 3.5 监管、执法与救济

- 【事实】中国：行政部门统筹 + 测评公布 + 民事赔偿（过错推定）+ 公益诉讼（E04 第六十一、六十九、七十条）。加州：CPPA 行政罚款（§1798.155）+ 总检察长民事罚款（§1798.199.90）+ 个人法定赔偿诉讼（§1798.150），2023 年起无整改期（E21、E30、E35）。
- 【分析】差异：中国救济更依赖行政监管与公益诉讼，加州保留较强的个人诉讼激励。优劣：前者适合处理"侵害众多个人权益"的规模化问题，后者适合个体维权但可能带来滥诉与和解成本。
- 【分析】对青年启示：在中国可通过投诉举报、民事诉讼、公益诉讼维权；金额口径须区分"每次违规"（罚款）与"每名消费者每次事件"（法定赔偿）。

### 3.6 制度取向

- 【事实】中国法律文本将个人信息保护与数据安全、国家主权与国家安全相连接（E04 第一条、E05 第一/四条）；CCPA 文本以消费者权利与企业义务为主（E21）。
- 【分析】差异源于立法定位不同：一是安全与发展并重的综合性立法，一是消费者保护型州法。**该差异是定位差异，不等于美国不重视安全，也不等于中国不重视个人权利。**
- 【分析】对青年启示：理解中国制度应从"人民安全"与"统筹发展和安全"入手；理解加州制度应从"消费者选择权 + 私人诉讼"入手。

## 四、可相互借鉴之处（【分析】，供讨论，不作结论）

1. 加州的"退出偏好信号（Global Privacy Control）"与"数据经纪人登记"（Delete Act）为降低个人行权成本、监管数据经纪行业提供参考（E25、E27、E29）。
2. 加州的法定赔偿与私人诉讼为个体维权提供直接激励（E21 §1798.150）。
3. 中国的"清单式告知""个人信息保护影响评估""合规审计""部门测评并公布"等工具，为平台治理提供制度化事前监管路径（E04 第五十四—五十六条、第六十一条；E07 第二十一条）。
4. 两地都在向"目的限定 + 个人控制 + 有效救济"三者结合的方向演进（E21 §1798.100(c)、§1798.121；E04 第六条、第二十八条）。

1. 不把加州 CCPA 表述为"美国法律"，须写"加州州法"；也不把加州法与美国联邦法混为一谈。
2. 不把中国全国性法律与加州州法当作同层级直接对比而不加说明。
3. 金额必须使用 **2025-01-01 起适用的调整值**（26,625,000 / 107—799 / 2,663 / 7,988），并注明调整依据为 §1798.199.95(d)（E35）；引用前应核对 CPPA 是否已发布新一次调整。
4. 不把本文件【分析】内容写成法律条文；引用条文一律回到 E04/E05/E02/E07/E21/E22/E35 原文核对条号与页码。
