# 习概（Xigai-Course）

《习近平新时代中国特色社会主义思想概论》课程汇报项目。

> 仓库名说明：GitHub 不接受中文仓库名，故仓库标识使用 `Xigai-Course`；本项目的正式中文名称为 **“习概”**，用于本课程汇报。

## 汇报主题

**青年身边的“网络安全”与“信息保护”**

核心论点：网络与数据安全是总体国家安全观在青年生活中的具体体现。
